# monoblock.app

La landing de Monoblock. Página estática servida con GitHub Pages en https://monoblock.app.

Para editarla: cambiá `index.template.html` y corré `python3 build.py`, que genera `index.html`
(pasa los colores de los SVG a `style` y mete las curvas de nivel de la gema de `gem-contours.txt`).
